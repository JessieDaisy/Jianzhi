# 剪枝 · 只做文字检查

双击 `打开剪枝.bat`，或直接用浏览器打开 `index.html` 即可使用。不需要联网、不需要安装任何东西、不需要服务器。

## 它是什么

一片叶子的形状，一次修剪的动作。剪枝只做两件事：

1. **意象检索**（四个模块标注「功能测试中」，是辅助功能）：写下你此刻想到的词句，它会把你的词**直接拆成具体意象**，再去文学史（小说 / 散文 / 戏剧 / 诗歌四类，共 **315 部作品、358 条场景句，其中 194 条原句**）里找**写了这些意象的句子**，把句子摆在你面前。每次给出 10 条，可以「换一换」。
2. **正文检查**：粘贴同人文正文（单次 20000 字符以内），找出读者容易读腻的地方，圈出来，并在正文里用浅绿色标出可替换处。

写完**直接按 Enter 就等于点了右下角的 ↑**（中文输入法选词时的回车不会被误当成发送）；想在框里自己分段就按 **Shift+Enter** 换行。文本框左下角还有一个带确认的「清空」。

版面按黄金分割：**正文区占 61.8%**，上面的四个检索模块占 38.2%（它们是辅助功能）。看检索结果觉得挤，可以点检索栏里的「放大检索区」临时把上面放大，再点一次还原。

它**不生成段落、不续写情节、不替你决定故事怎么走，也不会擅自改动你的一个字**。

## 几处设计上的取舍

- **不绕抽象概念**。你写「雪夜」，剪枝不会先抽象成「冷寂」，再拿这个概念去找作品；它会**先按整词「雪夜」找**，找不到再拆成「雪」+「夜」，直接找同一句里同时写了雪与夜的作品。
- **必须在同一句里共现**。一本书前面写了雪、很远的地方才出现夜，**不会**被算成「雪夜」的结果。同一句里同时写全的作品排在最前，只命中一部分的会被一道分隔线拦在下面，并标明"这句里没有：夜"。
- **意象同族**。搜「橙」也会给出只写了橘子、柑、丹橘、橙黄的句子；搜「雪」也会给出只写了雪色、霜雪、柳絮、梨花的句子。命中的同族词会标出来，例如「橙·同族（橘）」。同族表在 `assets/data.js` 的 `JZ.IMAGERY_FAMILY`。
- **场景匹配：字词不必出现在句子里**。搜「雪」也会给出写着霜、白、冷、柴门犬吠、踩着路面回来的句子；搜「橙」也会给出写着果园、枝头、熟透、果摊的句子。做法是**词 → 场景 → 句子**：`JZ.SCENE_LIB` 里列了二十多个场景（风雪夜归、围炉煮酒、渡口送别、果熟采摘、湖上观雪、古道瘦马……）和各自的特征词，一句里命中场景的关键元素 + 两个以上特征词，就算属于这个场景。命中的会标明「雪·同场景（风雪夜归）」，句首也会写清"这句没写这个词，但写的是同一个场景"。
- **不认识的字也能搜**。哪怕词库里没有的写法，也会照字面去句库找，不会再出现"输入了却一条都不显示"。
- **两种排序，一键切换**。结果栏右上角可选「**情天优先**」（默认，先排和恨海情天最相关的）或「**命中优先**」（先排句子里真的写了这个词的），选择会记住。无论选哪种，同档里都是外国文学 → 中国现当代 → 中国古代，且整词连写 > 两词紧邻 > 同句共现 > 只命中一部分 > 同场景。
- **「恨海情天」矢量，门槛很宽**。除了意象，剪枝还会算每一句的**爱意 / 恨意 / 纠缠**：只要沾到边（爱、念、等、别、离、重逢、错过、恨、怨、痛、泪……），就至少记 30%——**哪怕只是句子里有人、有情绪**（你、我、他、她、心、眼、手、笑、沉默……）也算沾边。只有纯写景、句子里没有人也没有情绪的（《江雪》《山居秋暝》那种）才算沾不上边。「恨」「等」这类词不会变成"必须同句出现"的硬条件，它们只影响这个矢量。
- **沾不上边的也照样列出来**，只是排在下面，中间用一道分隔线写着"以下与爱恨纠缠关系不大"，不再藏起来。
- **句子分两类，标得清清楚楚**。标「原文」的，是公有领域作品的原句（古代、近代，以及已过版权保护期的现代作者，如鲁迅、朱自清、老舍、徐志摩、戴望舒、萧红）；仍在版权保护期内的当代作品，标「场景概述」，用它写的是什么场景来说明，**不复录原文**。
- **只盯"读腻"，不盯"意象"**：右栏按这个顺序排列：**常态副词**（微微、缓缓、轻轻、忽然……）→ **常态化表述**（「皱了皱眉」「眉头一皱」「垂下眼眸」「眨了眨眼睛」「深吸一口气」）→ **反复出现的实词** → **本文关键意象（不标记）**。
- **点一下，左侧同步高亮**。右栏的每一个词都可以点：第一次点跳到它在正文里第 1 次出现的位置，再点跳到第 2 次，依次循环；正文里**所有出现的位置都会同时标出来**，当前这一处最醒目，并自动滚动到那里。
- **英文不参与**。Peter、Sherlock 这类英文名不统计、不高亮。
- **词是完整的，不切碎**。人名与昵称在切词前先整块认出（连同它们占用的位置一起保护），所以不会切出「荒的脸」这种碎片；片段里夹着「的 / 地 / 得 / 了 / 着 / 过」的候选词一律不要。实测：正文里写了「林见雪」「江砚」这类人名，人名一个字都不进统计，也不会被拆成「林」「见」「雪」。
- **明确不标记的三类东西**：
  1. **本文关键意象**。雪、月、夜色、灯光这类词是文章的场景骨架，也是情绪本身；它们分散在多个段落里反复出现属于风格，不算疲劳。这类词会被单独列出来给你看（出现次数 + 覆盖段落数），但不会标记、也不会给替换建议。
  2. **人名、昵称、称呼与代词**。姓名和昵称（小枝、阿砚、明明……）一起过滤；你、我、他、她、它、您、咱……一律不统计、不标记。
  3. **虚词**。的、地、得、了、吗、呢、是、就、都……不进入统计。
- **双阈值判定**：一个词被标出，要么它的**占比**超过阈值（默认 1.8%），要么它的**绝对次数**超过阈值（随篇幅自适应）。灵敏度可在设置里切换「宽松 / 标准 / 严格」。
- **替换建议默认关闭**：这是设置里的一个开关。开启后，鼠标停在浅绿高亮处 **0.618 秒**（黄金比例）会浮出几个方向不同的替换词。即便如此，也只有你亲手点下某一个词，那一处才会改变；每次替换都可以撤销，也可以一键「还原原文」。
- **粘贴超限整段取消**：超过 20000 字符时不会默默截断你的文本，而是取消这次粘贴并告诉你超了多少。
- **全部在本机运行**：没有后端、没有网络请求、没有云端存储，历史记录只保存在你自己的浏览器里。

## 视觉

白底 + 明亮的绿（第一版配色）：#EFF9F2 / #BFE7CD → #7FC9A1 → #2E9A6A → #0A3324，四片叶子从左上到右下逐个加深，浅绿高亮 #D9F3E2。

## 联网扩词（可选，默认关闭）

在**设置**里可以打开「联网扩词」。它的作用只有一个：点检索时先把你输入的词发给 AI，让它扩成具体的意象词与场景词（例如「雪夜」→ 霜、犬吠、柴门、归人、冻、白屋），**然后仍然在本地句库里检索**——句子永远来自本地库，AI 不生成正文，也不改你的稿子。

- **只发送你输入的那几个关键词**，不发送正文；正文检查全程在本机完成。开关关闭时网页完全不联网。
- 接口填 OpenAI 格式的即可（OpenAI、DeepSeek、智谱、Moonshot、硅基流动……）：填「接口地址 + 模型名 + API Key」，Key 只存在本机 localStorage。这个 HTML 文件如果发给别人，请先清空 Key。
- 接口失败会自动回退到纯本地检索，并在结果上方写明原因，不会卡住。
- 命中 AI 扩展词的句子会标「AI 扩词命中」，排在字面命中与场景命中之后。

## 目录

```
index.html            页面结构
打开剪枝.bat          双击启动
assets/style.css      白 + 绿的视觉样式
assets/data.js        作品库、情感坐标、词表（可自行扩充）
assets/app.js         分词、高频词统计、风格检索
assets/favicon.svg    网页图标（叶片 + 回纹 + 剪口）
assets/icon-*.png     应用图标（180 / 192 / 512 / 32）
```

想扩充检索库，最直接的是加句子：在 `assets/data.js` 的 `JZ.SCENES` 里，按
`"篇名": [["句子", 是否原文(1/0), "意象标签|用竖线分隔"]]` 的格式加即可，作品本身在 `JZ.WORKS` 里加一行。
其余可调的几处：`JZ.IMAGERY` 关键意象表（放进去的词不会被标记为疲劳）、
`JZ.ROUTINE_PHRASES` 常态化表述与替换建议、`JZ.SYNONYMS` 单词替换表。
